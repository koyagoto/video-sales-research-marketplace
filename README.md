# 映像営業調査プラグイン v3.1.7

映像制作者向けの営業候補調査、100点採点、段階的な再探索、営業リスト管理をまとめた公開配布用Codexプラグインです。v3.1.7では、v3.1.6までの調査・採点・プロフィール引き継ぎ・発注元分散枠・履歴保護を維持したまま、営業CSVを表計算ソフトで開いた際に入力値が数式として扱われない保存対策を追加しています。

## 主な機能

- プロフィール一括入力
- 明示的に保存したプロフィールと営業実績の同一ワークスペース内引き継ぎ
- 公式情報を使った営業候補調査
- 100点満点の適合度採点と証拠充足率
- 候補不足時の段階的な再探索
- 従来の上位5社を維持した、非制作会社の発注元分散枠（最大3社、合計最大8社）
- 公式ドメイン、応募経路、詐欺・なりすましの安全確認
- 問い合わせ文などの下書き作成
- 送信、返信、面談、提案、受注、失注、保留、除外の管理
- 営業活動履歴と件数・率の集計

詳しい画面順の説明は、[はじめての方向け 導入・運用ガイド（PDF）](docs/映像営業調査_v3.1.7_はじめての方向け導入・運用ガイド.pdf)をご覧ください。

## 初回インストール（Windows／macOS・約20分）

この準備は最初の1回だけです。公開リポジトリを読み込むため、利用者側のGitHubアカウントは不要です。

### 1. お使いのパソコンのターミナルを開く

- Windows：スタートメニューで `PowerShell` を検索して開きます。
- macOS：Finderで「アプリケーション」→「ユーティリティ」→「ターミナル」の順に開きます。

Codex画面の「何でもどうぞ」と書かれた入力欄とは別の画面です。

### 2. Codex CLIをインストールする

お使いのパソコンに合う1行だけを貼り付け、Enterキーを押します。`chatgpt.com`の公式インストーラー以外は使用しません。

Windows：

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
```

macOS：

```sh
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```

`Codex CLI ... installed successfully.`と表示されたら成功です。`Start Codex now? [y/N]`と表示された場合は、`n`を入力してこの手順を続けて構いません。

### 3. インストールを確認する

WindowsはPowerShellをいったん閉じ、もう一度開いてから確認します。

```powershell
codex --version
```

macOSは次の2行を順番に実行します。

```sh
source ~/.zprofile
```

続けて、Codex CLIが使えることを確認します。

```sh
codex --version
```

バージョン番号が表示されたら次へ進みます。

### 4. 正規の配布元を登録する

```sh
codex plugin marketplace add https://github.com/koyagoto/video-sales-research-marketplace.git
```

エラーが表示されず、通常の入力待ちに戻れば登録完了です。

### 5. プラグインをインストールする

```sh
codex plugin add video-sales-research@video-sales-research-public
```

`Added plugin 'video-sales-research'`と表示され、インストール先の末尾に`3.1.7`が表示されたら成功です。

### 6. アプリを再起動して開始する

1. Codexデスクトップアプリを完全に終了します。Windowsは通知領域にアプリが残っていないことを確認し、macOSは`command + Q`で終了します。
2. アプリを再起動します。
3. 利用者ごとに新しいプロジェクトまたは作業フォルダを選び、新規チャットを作成します。
4. 次の文章を送信します。

> 映像営業調査プラグインを使用して、初期プロフィールの一括入力画面を表示してください。まだ企業調査は始めないでください。

入力画面が表示されたらインストール確認は完了です。以後の通常利用では、ターミナル操作や再インストールは必要ありません。

## 初回インストールで困った場合

### `command not found`または「認識されていません」と表示された

ターミナルを完全に閉じてからもう一度開き、`codex --version`を実行します。macOSでは、その前に次も実行します。

```sh
source ~/.zprofile
```

それでも解消しない場合は、エラー全体のスクリーンショットを保存して運営者へ送ってください。Codex CLIをまだインストールしていない場合は、手順2から実行します。

### 途中で英語の作業中表示が出た

プロフィールやポートフォリオの確認中に英語の進捗表示が出る場合があります。エラー表示がなければ、同じ依頼を再送せず完了まで待ちます。

### 別のエラーが表示された

同じ命令を何度も繰り返さず、エラー全文とターミナル全体のスクリーンショットを配布者へ送ります。正規URLは `https://github.com/koyagoto/video-sales-research-marketplace` です。同名の第三者リポジトリ、検索広告、短縮URLは使用しません。

## データとプライバシー

- 公開リポジトリに利用者のプロフィールや営業データは含まれません。
- プロフィールは現在の利用者・現在のチャットだけを対象にします。利用者が明示的に保存を依頼した場合だけ、現在の作業フォルダ内の `営業管理/プロフィール.md` へ保存できます。
- 営業データを保存する場合は、利用者が確認したローカル作業フォルダを使用します。
- パスワード、認証コード、身分証、カード情報、銀行ログイン情報、APIキーは入力・保存しません。
- 調査や下書き作成だけでは、応募、メール、フォーム送信は実行しません。

詳細は [PRIVACY.md](PRIVACY.md) と [SECURITY.md](SECURITY.md) を確認してください。

## バージョン互換性

v3.1.7はv3.0.3の調査・採点基準、v3.1.0の営業リスト機能、v3.1.1の公開配布向け安全対策、v3.1.3の発注元分散枠、v3.1.4のプロフィール引き継ぎ、v3.1.5の表示仕様、v3.1.6の読取専用動作と履歴保護を維持しています。プロフィール引き継ぎは、利用者が選択した同じ作業フォルダ内だけで行います。営業CSVの列構成は変更していません。v2以前の97点固定基準は使用しません。旧ZIPや旧プラグインを同じ新規チャットで併用しないでください。

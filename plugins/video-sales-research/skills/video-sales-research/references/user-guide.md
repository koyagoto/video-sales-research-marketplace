# 映像営業調査 v3.1.4 プラグイン利用説明書

## 初回だけ行う準備（Windows／macOS・約20分）

この準備は最初の1回だけです。公開リポジトリを読み込むため、利用者側のGitHubアカウントは不要です。

### 1. お使いのパソコンのターミナルを開く

- Windows：スタートメニューで `PowerShell` を検索して開きます。
- macOS：Finderで「アプリケーション」→「ユーティリティ」→「ターミナル」の順に開きます。

Codex画面の「何でもどうぞ」と書かれた入力欄とは別の画面です。

### 2. Codex CLIをインストールする

お使いのパソコンに合う1行だけを貼り付け、Enterキーを押します。`chatgpt.com`の公式インストーラー以外は使用しません。

Windows：

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
```

macOS：

```sh
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```

`Codex CLI ... installed successfully.`と表示されたら成功です。`Start Codex now? [y/N]`と表示された場合は、`n`を入力してこの手順を続けて構いません。

### 3. インストールを確認する

WindowsはPowerShellをいったん閉じ、もう一度開いてから確認します。

```powershell
codex --version
```

macOSは次の2行を順番に実行します。

```sh
source ~/.zprofile
```

続けて確認します。

```sh
codex --version
```

バージョン番号が表示されたら次へ進みます。

### 4. 正規の配布元を登録する

```sh
codex plugin marketplace add https://github.com/koyagoto/video-sales-research-marketplace.git
```

配布者から案内された正規URLだけを使用します。検索で見つけた同名リポジトリ、第三者の複製、検索広告、短縮URLは使用しません。

### 5. プラグインをインストールする

```sh
codex plugin add video-sales-research@video-sales-research-public
```

`Added plugin 'video-sales-research'`と表示され、インストール先の末尾に`3.1.4`が表示されたら成功です。

### 6. アプリを再起動する

Codexデスクトップアプリを完全に終了し、もう一度起動します。Windowsは通知領域にアプリが残っていないことを確認し、macOSは`command + Q`で終了します。

## 通常利用を開始する

初回インストール後は、ターミナル操作や再インストールは必要ありません。

### 1. 新規チャットを開く

利用者ごとに新しいチャットを作成します。ほかの利用者が使用したチャットや、旧版を読み込んだチャットは使い回しません。

以前のv2やv3.0 ZIPは、同じ新規チャットへ添付しません。

### 2. プロフィールを一括入力する

次のように送信します。

> 映像営業調査プラグインを使用して、初期プロフィールの一括入力画面を表示してください。まだ企業調査は始めないでください。

表示されたテンプレートをコピーし、分かる範囲でまとめて入力して送信します。内容を確認し、正しければ「この内容で登録する」と返信します。

URLで確認できる実績を一件ずつ入力する必要はありません。案件によって変わる交通費、宿泊費、日程、納期、支払条件などは、必要な段階で確認します。

パスワード、認証コード、身分証番号・画像、カード情報、銀行ログイン情報、APIキーなどは入力しません。

## 旧版から更新して続きから使う

### 1. 更新前のチャットで保存する

これまで使用していたチャットへ、次の文章を送信します。

> 現在登録されているプロフィール、営業リスト、活動履歴を、現在のプロジェクト内の「営業管理」に保存してください。プロフィールは「プロフィール.md」として保存し、既存の営業データは消さないでください。

保存先を確認された場合は、現在のプロジェクト内の `営業管理` を指定します。まだチャットへ報告していない返信や面談がある場合は、保存前にその内容を伝えます。

### 2. ターミナルで更新する

次の2行を一行ずつ実行します。

```sh
codex plugin marketplace upgrade video-sales-research-public
```

```sh
codex plugin add video-sales-research@video-sales-research-public
```

`codex`が見つからない場合はターミナルを閉じて開き直します。macOSでは`source ~/.zprofile`を実行してから、上の2行をもう一度実行してください。

インストール先の末尾に `3.1.4` と表示されたら、Codexデスクトップアプリを完全に終了し、もう一度起動します。Windowsは通知領域にアプリが残っていないことを確認し、macOSは`command + Q`で終了します。

### 3. 同じプロジェクトの新しいチャットで読み込む

以前と同じプロジェクトを選び、新しいチャットへ次の文章を送信します。

> 映像営業調査 v3.1.4を使用してください。現在のプロジェクト内の「営業管理」から、保存済みプロフィールと営業実績を読み込んでください。プロフィールの確認内容と、現在の送信、返信、面談などの営業状況を表示してください。まだ会社調査は始めないでください。

表示されたプロフィールが正しければ「この内容で登録する」と返信します。保存済みプロフィールが見つからない場合だけ、一括入力画面が表示されます。

プロフィールと営業実績の読込だけでは、問い合わせ、応募、営業リストへの新規登録は行いません。

## 初回インストールで困った場合

### `command not found`または「認識されていません」と表示された

ターミナルを完全に閉じてからもう一度開き、`codex --version`を実行します。macOSでは、その前に次も実行します。

```sh
source ~/.zprofile
```

それでも解消しない場合は、エラー全体のスクリーンショットを保存して運営者へ送ってください。Codex CLIをまだインストールしていない場合は、初回準備の手順2から実行します。

### 途中で英語の作業中表示が出た

プロフィールやポートフォリオの確認中に英語の進捗表示が出る場合があります。エラー表示がなければ、同じ依頼を再送せず完了まで待ちます。

### 別のエラーが表示された

同じ命令を何度も繰り返さず、エラー全文とターミナル全体のスクリーンショットを配布者へ送ります。

## 営業候補企業を調査する

> 現在のプロフィールを使って、有償の映像制作案件につながる営業候補企業を調査してください。現在有効な公式情報を確認し、点数と根拠を表示してください。

結果は100点満点で採点されます。

- 95～100点：強く推薦
- 90～94点：暫定推薦
- 80～89点：条件確認候補
- 70～79点：開拓候補
- 69点以下：調査候補または非推薦

推薦には、原則として適合度90点以上と証拠充足率75%以上が必要です。90点以上がない場合も採点基準を下げず、検索語、発注元、動画用途、地域の順に探索範囲を広げます。

通常の上位5社に加え、広告代理店・PR会社、Web制作・デジタルマーケティング会社、一般企業などから最大3社を「発注元分散枠」として表示します。合計表示は最大8社です。分散枠も同じ100点配点と証拠基準で評価し、通常枠との重複を除きます。安全性を確認でき、現在の外注需要または商取引につながる経路を公式情報で確認できる会社が3社未満の場合は、無理に枠を埋めず1～2社、または0社と不足理由を表示します。90点未満の会社を表示する場合も、正式推薦にはせず実際の判断区分を示します。

## 営業リストを作る

初回だけ、次のように送信します。

> 営業リストを作成し、今回の候補を登録してください。

保存先を一度だけ確認します。通常は現在の作業フォルダ内の「営業管理」を使用します。共有端末の場合は、必ず利用者ごとに別の作業フォルダを選んでください。

保存を希望しない場合は「チャット内だけで管理」と伝えれば、ファイルを作成しません。

## 進捗を更新する

普通の文章で伝えれば更新できます。

- 「株式会社○○へ今日問い合わせを送信した」
- 「株式会社○○から返信が来た」
- 「株式会社○○と8月20日に面談」
- 「株式会社○○へ提案書を提出した」
- 「株式会社○○を受注した」
- 「株式会社○○は今後表示しない。理由は募集終了」

文章を作成しただけでは送信済みになりません。実際に送信したと利用者が伝えた場合だけ記録します。

## 件数を確認する

> 営業リストの現在状況を表示し、登録、送信、返信、面談、提案、受注、失注、保留、除外の企業数と、返信率・面談化率・受注率を集計してください。

営業リストには企業ごとの現在状態、営業活動履歴には送信・返信・面談などの出来事が残ります。

## 更新と旧版の扱い

プラグイン更新後はアプリを再起動し、新しいチャットから使用します。明示的に保存した `プロフィール.md` と既存の営業リストCSVは、プラグイン本体とは別の作業フォルダに保存されるため、通常のプラグイン更新では上書きされません。

旧ZIP方式が必要な場合は、別の新規チャットでv3.0.3だけを使用します。プラグインとZIPを同じチャットで混在させません。

## 安全に利用する

- 公式企業サイトと、そこから確認できる正式な応募経路を優先します。
- 先払い、登録料、ギフトカード、暗号資産送金を求める案件には応じません。
- パスワード、認証コード、身分証、銀行ログイン情報を相手へ送りません。
- 不審な添付ファイル、マクロ、アプリ、遠隔操作ソフトを開いたりインストールしたりしません。
- 応募先ドメインが企業公式ドメインと異なる場合は、公式窓口へ別経路で確認します。
- プロフィールや営業CSVを公開GitHub、公開リンク、共有フォルダへ置きません。

## 応募・送信について

調査、営業リスト登録、問い合わせ文作成だけでは、応募、メール、問い合わせフォームは送信されません。外部送信は利用者が明示的に依頼し、送信内容と送信先を確認した場合だけ行います。

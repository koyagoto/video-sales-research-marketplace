# 映像営業調査プラグイン v3.1.1

映像制作者向けの営業候補調査、100点採点、段階的な再探索、営業リスト管理をまとめた公開配布用Codexプラグインです。v3.1.1では、個人情報の公開防止、なりすまし・詐欺案件の検知、外部送信前の確認を強化しています。

## 主な機能

- プロフィール一括入力
- 公式情報を使った営業候補調査
- 100点満点の適合度採点と証拠充足率
- 候補不足時の段階的な再探索
- 公式ドメイン、応募経路、詐欺・なりすましの安全確認
- 問い合わせ文などの下書き作成
- 送信、返信、面談、提案、受注、失注、保留、除外の管理
- 営業活動履歴と件数・率の集計

## インストール

正規の公開リポジトリ `koyagoto/video-sales-research-marketplace` を使います。

```text
codex plugin marketplace add koyagoto/video-sales-research-marketplace
codex plugin add video-sales-research@video-sales-research-public
```

インストール後はChatGPTデスクトップアプリを再起動し、新規チャットで使用します。正規URLは `https://github.com/koyagoto/video-sales-research-marketplace` です。同名の第三者リポジトリや短縮URLは使用しません。

## データとプライバシー

- 公開リポジトリに利用者のプロフィールや営業データは含まれません。
- プロフィールは現在の利用者・現在のチャットだけを対象にします。
- 営業データを保存する場合は、利用者が確認したローカル作業フォルダを使用します。
- パスワード、認証コード、身分証、カード情報、銀行ログイン情報、APIキーは入力・保存しません。
- 調査や下書き作成だけでは、応募、メール、フォーム送信は実行しません。

詳細は [PRIVACY.md](PRIVACY.md) と [SECURITY.md](SECURITY.md) を確認してください。

## バージョン互換性

v3.1.1はv3.0.3の調査・採点基準とv3.1.0の営業リスト機能を維持しています。v2以前の97点固定基準は使用しません。旧ZIPや旧プラグインを同じ新規チャットで併用しないでください。
